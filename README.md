# 🍜 ラーメンタイマー

Windowsのデスクトップの隅に置ける、小型ウィジェット風のPython製タイマーです。

## ダウンロードと起動

1. このページ上部の **Code → Download ZIP** を押してダウンロードします。
2. ZIPファイルを右クリックして **すべて展開** します。
3. Pythonをインストールしていない場合は、[Python公式サイト](https://www.python.org/downloads/windows/)からインストールします。従来のインストーラーを使う場合は **Add Python to PATH** を選んでください。
4. 展開したフォルダの **ラーメンタイマー_ウィジェット起動.bat** をダブルクリックします。

`ramen_timer_widget.py` と起動用の `.bat` は、同じフォルダに置いてください。
Python標準ライブラリのみを使用します。追加のpipインストールは不要です。

起動しない場合は、そのフォルダでターミナルを開き、次のコマンドを実行するとエラーを確認できます。

```console
python ramen_timer_widget.py
```

## 使い方

| 操作 | 動作 |
| --- | --- |
| 3分・4分・5分ボタン | 選んだ時間で計測を開始 |
| 時間表示をクリック | 一時停止・再開 |
| ＋、またはウィジェットの背景などを右クリック | 好きな時間を入力して開始 |
| ↻ ボタン | 計測を止めて3分に戻す |
| 上部のタイトル部分をドラッグ | 好きな場所に移動 |
| × ボタン | 終了 |

自由時間は `3:30` で3分30秒、`210` で210秒を指定できます。
指定できる合計時間は1秒から24時間までです。
計測中に別の時間を選ぶと、その時間で最初から計測します。

## 時間になったら

- Windowsでは4回のビープ音が鳴ります。
- 時間表示が赤くなり、下の表示が「できた！！！ 🍜✨」に変わります。
- 背景が短く点滅します。

ウィジェットは常に最前面に表示されます。Windowsの通知機能は使用していません。
音の聞こえ方はパソコンの設定や使用環境によります。

## 動作環境

- Windows / Python 3（Tkinterが使える環境）
- Windows向けの起動ファイルと通知音を用意しています。

パソコンを起動しただけでは自動起動しません。使うときに起動ファイルを開いてください。
